# 💻 LiteScript — My Own Programming Language

**A custom programming language built to explore compiler design and programming language development.**

LiteScript is a programming language project focused on understanding how programming languages are designed, processed, and executed. It explores core concepts of compiler construction, language syntax, and the steps involved in translating source code into meaningful operations.

## 🚀 Project Overview

The goal of LiteScript is to build a simple programming language with its own syntax and processing logic while gaining practical experience in compiler design and language implementation.
